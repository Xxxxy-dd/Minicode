## 简历项目描述

MiniCode Agent：参考 Claude Code 架构实现本地 AI Coding Agent Runtime，构建 Query Loop、Tool Calling、Skill Routing、Memory System、Context Compression、Agent Team、Git Worktree 隔离执行与安全审查机制，支持多任务代码理解、修改、测试和审计流程。设计中心化多 Agent 协作架构、Prompt Injection 防御链路和可解释 Eval Harness，在本地权限边界内提升复杂 Coding 任务的稳定性、安全性和可展示性。

## 简历技术亮点

- 设计 Skill 分层路由系统，将原子 Tool、高层 Skill 与 Skill 目录分层组织，结合任务意图识别、元信息标签、适用边界和示例进行召回与可选 LLM 精排，降低 Skill 增长下的检索噪声和 Token 成本。
- 设计自进化 Memory System，将项目约定、用户偏好、流程经验和 failure memory 沉淀为可复用资产，并通过 deterministic admission、secret rejection、duplicate/conflict/stale 策略控制长期状态质量。
- 设计分层 Context Compression 机制，将大工具结果压缩为 `ContextFrame`，通过 `EvidenceRef` 保留失败、diff、测试和 reviewer evidence，提升长任务上下文稳定性。
- 设计中心化 Agent Team 协作架构，由主 Agent 统一规划、审批和质量控制，子 Agent 以受限 Tool Call 执行 explorer/reviewer/tester/security-reviewer/implementer 等角色，并返回结构化 evidence。
- 设计 Git Worktree 隔离执行机制，在 clean repo 中创建临时 worktree，implementer 只生成 patch proposal，tester/reviewer/security-reviewer 审查后由主 Agent 汇总，避免自动 merge 污染用户 workspace。
- 构建权限与安全审查链路，结合路径沙箱、命令风险分类、Prompt Injection 检测、trace redaction 和 Eval report evidence，对文件写入、命令执行、非可信内容注入进行统一治理。

## 两分钟讲述稿

这个项目是一个本地 AI Coding Agent Runtime，不是普通聊天壳。用户任务进入 AgentLoop 后，模型不能直接改文件或执行命令，只能请求注册工具；真实动作都要经过 ToolSpec、PermissionPolicy、preview approval 和 TraceStore。

为了解决复杂 Coding 任务不稳定的问题，我做了三层能力：第一层是 Skill Routing，用任务元信息选择合适工作流；第二层是 Memory System，把项目约定、用户偏好和失败经验沉淀成可召回记忆；第三层是 Context Compression，把长工具输出压缩成结构化 ContextFrame，同时保留 evidence refs。

为了解决单 Agent 质量和安全边界问题，我做了中心化 Agent Team。主 Agent 保留控制权，子 Agent 通过受限工具执行 explorer、reviewer、tester、security-reviewer、implementer 等角色，并按 EvidenceContract 返回结果。涉及实现任务时，会在 clean repo 中创建 Git Worktree，implementer 只产出 patch proposal，不自动 merge 回用户 workspace；dirty repo 会直接返回 blocker。

最后，我用 Eval Harness 证明这些能力不是口头描述。当前 V1.2 有 22 个本地 benchmark task，覆盖 safety、team、worktree、memory、context、skills 等路径，最新 full 配置 22/22 通过。Markdown report 会展示 Safety Evidence、Team Evidence、Worktree Evidence、Memory Evidence 和 Context Compression Evidence，可以直接看到 prompt injection finding、merge blocker、patch proposal、memory recall 和 compression refs。

## 当前边界

- 不做 SaaS 或 Web UI。
- 不自动 push、merge、创建远程 PR。
- 不把所有安全判断交给 LLM。
- Prompt Cache 目前是通过 PromptSegment / ContextFrame 预留稳定上下文边界，不宣称已经接入完整缓存服务。
- Eval task 是本地轻量 benchmark，适合证明架构链路和回归，不等价于大型公开 SWE benchmark。
