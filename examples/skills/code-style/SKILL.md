# Code Style

Use this skill when the task asks for cleanup, refactoring, readability, or style consistency.

Workflow:

1. Identify the smallest behavior-preserving change that improves clarity.
2. Match the naming, layout, error handling, and test style already used nearby.
3. Avoid broad rewrites unless the task explicitly asks for them.
4. Run focused tests or explain why they were not run.

Output expectations:

- Summarize what changed and why.
- Call out any behavior that intentionally stayed the same.
- Mention the validation command used.
