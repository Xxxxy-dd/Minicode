# Refactoring

Use this skill when the task asks for code cleanup, duplicate removal, or structure improvements while keeping behavior unchanged.

Workflow:

1. Identify the behavior that must stay the same.
2. Inspect the smallest set of files needed for the refactor.
3. Make one focused structural change at a time.
4. Re-run the most relevant tests or checks after the change.
5. Summarize what changed and the evidence that behavior was preserved.
