# Release Polish

Use this skill when the task is about getting a project ready to ship or present.

Workflow:

1. Inspect README, docs, examples, and recent changes.
2. Check that demo commands still match the implemented behavior.
3. Run or identify the smallest useful smoke test.
4. Update release notes or checklist with concrete user-visible changes.
5. Call out remaining limitations instead of implying unfinished work is done.
