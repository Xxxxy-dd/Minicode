# Repo Onboarding

Use this skill when the task is to understand an unfamiliar project before changing it.

Workflow:

1. List the top-level project structure and identify the main language or framework.
2. Read the most useful entry documents or configuration files.
3. Map important modules, tests, examples, and docs.
4. Note how to run checks or demos when that is discoverable.
5. Summarize the project in terms of responsibilities, workflows, and likely next files to inspect.
