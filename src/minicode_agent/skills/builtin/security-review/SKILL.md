# Security Review

Use this skill when the task concerns command safety, path boundaries, credentials, permissions, or risky tool behavior.

Workflow:

1. Identify the asset or boundary being protected.
2. Inspect the relevant permission, path, command, and trace handling code.
3. Look for bypass paths, missing reasons, and unredacted sensitive values.
4. Add or recommend focused regression coverage for each risk.
5. Report risks with severity, evidence, and a concrete mitigation.
